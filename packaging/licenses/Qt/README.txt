Qt / Qt for Python open-source license texts
===========================================

These unmodified texts were retrieved on 2026-10-22 from the official Qt
qtbase repository at tag v6.11.2. Exact URLs and SHA-256 hashes are recorded
in SOURCES.json. They supplement the notices copied from the installed
PySide6, PySide6_Essentials, PySide6_Addons and shiboken6 distributions.

The four installed 6.11.2 wheel metadata records declare:
LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only
Their packaged License-File contains only LicenseRef-Qt-Commercial.txt,
so that wheel file alone does not provide the declared open-source texts.

LGPL version 3 incorporates GPL version 3; both full texts are included.
GPL version 2 is included to preserve the other stated upstream alternative.
The presence of these alternatives does not change TraceAtlas's own license
or select GPL for the application. The commercial text copied from the wheels
is an upstream notice, not evidence that TraceAtlas holds a commercial license.

Qt/PySide6 libraries are dynamically linked and distributed as separate files.
The final build specification determines which modules are shipped; the
generated inventory.json lists the Qt DLLs, plugins and Python bindings found
in the actual application bundle when these notices are assembled.
